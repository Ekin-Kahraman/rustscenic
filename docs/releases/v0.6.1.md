# RustScenic v0.6.1: documentation and reproducibility fixes

Released 9 November 2026.

- Fixed PyPI links and images with a version-pinned package description.
- Updated the PBMC3k notebook to the verified public v0.6.0 package and
  corrected the quickstart release link.
- Archived the exact HPC workflow runner and documented its thread settings.

Analysis code, defaults and benchmark results are unchanged from v0.6.0.
The GitHub README wording, layout and figures are preserved, with current
version labels updated. Authorship, credits and Apache-2.0 licensing are unchanged.

## Install

```bash
python -m pip install --upgrade rustscenic
```
