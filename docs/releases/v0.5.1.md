# RustScenic v0.5.1 candidate: input safety and run provenance

**Draft for review. This candidate is not published. The current PyPI and
GitHub release is v0.5.0.**

Published release: `v0.5.0`.

RustScenic v0.5.1 is proposed as a patch release for safer AUCell inputs,
more informative GRN run records and clearer adoption examples. Valid-input
analysis kernels, public function signatures and defaults are unchanged.

## Input safety

AUCell tuple inputs must contain a two-dimensional cells-by-genes matrix and
exactly one gene name per column. Malformed inputs now raise an actionable
`ValueError` before diagnostics or scoring. Previously, a mismatched name list
could produce plausible scores and gene-coverage results while unnamed columns
still affected rankings. Valid-input scores and duplicate-symbol aggregation
are preserved.

## GRN settings in result metadata

`grn.infer(...).attrs["grn_fit"]` gains normalized seed, fitting and output-filter
settings, carried through to pipeline manifests, including RNA-only runs.
Existing keys and fitted-tree summaries remain present. New fields are:

- `seed`, `learning_rate`, `max_features` and `max_depth`;
- `top_targets_per_tf` and `min_importance`;
- `target_block_size_requested` and `target_block_size_effective`.

The effective block size is `null` because the compatibility option is ignored
by flat scheduling. Accepted nonfinite importance thresholds are recorded as
`"NaN"`, `"Infinity"` or `"-Infinity"` strings so manifests remain strict JSON;
filtering behavior is unchanged. These settings do not capture the complete
inputs, transformations, software environment or hardware needed for replay.

## Documentation and examples

- Add a source-derived Python API reference with signatures, parameter
  defaults, result fields and first-party reexports.
- Replace the ambiguous Seurat converter recipe with explicit normalized RNA
  `data`-layer selection, sparse matrix/ID exchange and barcode-indexed activity
  return. The executed interoperability check uses SeuratObject 5.4.0 and Matrix
  on macOS; it does not validate a full Seurat pipeline or third-party converters.
- Add a browser viewer and downloadable precomputed endothelial-cell example
  from the published CELLxGENE resource, with provenance, study citations and
  checksums. The starter inspects saved results and does not rerun inference or
  constitute a new biological validation experiment.
- Improve installation, quickstart, citation and contributor guidance.

## Validation and scope

The AUCell source fix passed 94 focused tests, with 21 new cases, and ten actual
before/after valid cases matched exactly in score bytes, coverage and metadata.
Its reviewed source and merged main commit passed all 20 audit jobs and the docs
workflow. GRN provenance was checked with dense/sparse settings, strict JSON,
an actual RNA-only manifest round-trip and unchanged inference outputs.

Those source checks are not yet a v0.5.1 artifact-release validation. Before
publication, review the exact candidate commit, all five platform wheels,
source distribution, package/native versions and installation smoke results.

No new performance or biological accuracy result is claimed. Historical
v0.5.0 benchmark measurements retain their original inputs, hardware and scope.
Full output parity with pySCENIC/SCENIC+ is not claimed.

## Upgrade after publication

```bash
python -m pip install --upgrade rustscenic==0.5.1
```

The existing Python 3.10–3.13 and platform support scope is unchanged. This draft
does not announce package availability or authorize a tag, release or upload.
