# RustScenic v0.7.0: exact TF binning in GRN inference

Released 19 November 2026.

- GRN inference now gives every distinct TF value its own bin (up to 65,535
  per TF), so candidate split thresholds match scikit-learn's.
  RustScenic 0.6 merged values into at most 255 bins. A pre-specified
  replication at 20,000 cells failed three of its four fidelity checks against
  arboreto: target rankings agreed with arboreto's less closely than
  arboreto's own runs agree across seeds (fidelity 0.74 to 0.84 against a 0.90
  criterion; the fourth check passed at 0.91). Post hoc diagnosis attributed
  the gap to the 255-bin quantisation. Refits with exact binning gave 0.95 to
  0.97 under the default stopping rule and 0.985 with `paired_oob`.
- Networks therefore change from v0.6. `max_bins=255` (API), `grn --max-bins 255`
  or `rustscenic.pipeline.run(..., grn_max_bins=255)` reproduces v0.6 networks
  bit for bit.
- New `early_stop_mode="paired_oob"` applies arboreto's 25-round monitor to
  same-mask out-of-bag improvements, the definition scikit-learn used before
  1.3. The default stopping rule is unchanged (`"arboreto"`).
- Cost: split search now computes gains only for the bins a node occupies,
  which does not change results. On the bone-marrow replication input (20,000
  cells, 5,000 genes, 1,069 TFs; 10-core laptop, two alternating runs each), a
  v0.7.0 release-candidate build took 284.6 to 285.5 s against 271.7 to
  272.0 s for a local v0.6.1 build (4.9% longer), with the same 0.66 to
  0.67 GB peak memory. A single rerun of each published wheel gave 4.7%. On
  the 1,306,127-cell mouse atlas (3,000 genes, 256 TFs, one run each), v0.7.0
  took 8.5% longer and used 1.3% more peak memory. The binned TF matrix takes
  2 bytes per cell per TF instead of 1.
- The audited `rustscenic validated` recipes pin `max_bins=255`, so they keep
  reproducing their audited results.

AUCell, cisTarget, topics, ATAC preprocessing, enhancer links and eRegulon
assembly are unchanged. Published workflow benchmarks were measured with the
v0.5 and v0.6 engines.

Corrected 20 November 2026: the fidelity summary now reports all four checks
and both stopping rules, the timings name the builds measured, and the
pipeline call is given in full.

## Install

```bash
python -m pip install --upgrade rustscenic
```
