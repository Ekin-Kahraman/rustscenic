# RustScenic v0.5.0 — gene networks from 1.3 million cells, with less memory

RustScenic v0.5.0 makes large single-cell gene-network analysis more practical:
it processed 1.3 million mouse-brain cells in under 47 minutes on 16 CPU cores.
This release combines lower-memory Rust code with a Python interface and
improvements to how gene networks are fitted and interpreted.
Created and maintained by Ekin Kahraman, the project is developed in collaboration
with the Kuan-Lin Huang Lab at the Icahn School of Medicine at Mount Sinai.

## Performance highlights

- **1,306,127 real cells:** RNA GRN inference in **46m42s**, with **4.28 GB**
  execution peak memory on 16 CPU cores, using 2,095 selected genes and 256 TFs.
- **3.3x faster with about 81% less peak physical memory** than arboreto in the
  controlled same-node 20k-cell GRN comparison. Fitted-tree totals differed
  by only 0.094%; this does not imply identical edge rankings.
- **21.4% lower topic-model peak memory** on real mouse-brain ATAC data,
  with byte-identical outputs across three baseline and three optimised runs.
- **Near-proportional measured pipeline scaling:** doubling synthetic inputs
  from 100k to 200k cells used 1.995x peak memory and 2.063x seven-stage compute
  time in the controlled same-node check.

The million-cell result is execution on prepared RNA, not a full raw-data
workflow: separate full-data preparation peaked at 71.49 GB. The seven-stage
scale check used synthetic inputs and a 20-estimator GRN. The topic memory audit
used five sweeps and tests storage efficiency, not convergence. Full commands,
hardware, parameters and output checks are recorded in the
[real-RNA benchmark](https://github.com/Ekin-Kahraman/rustscenic/blob/0c8eb00539e3860c78e452c8661cc2735c169386/validation/scaling/IFB_REAL_RNA_GRN_2026-08-28.md) and
[IFB scaling and memory audit](https://github.com/Ekin-Kahraman/rustscenic/blob/0c8eb00539e3860c78e452c8661cc2735c169386/validation/scaling/IFB_SCALE_2026-08-28.md).

## What changed

- Reduced memory used to track cells during gene-network fitting and tokens
  during parallel topic modelling, preserving the checked outputs.
- Corrected when gene-network fitting stops to follow arboreto's rule; run
  summaries now report how many trees were actually fitted.
- Added gene-correlation calculations and separate positively and negatively
  correlated target sets, carried through downstream analysis. These are
  available through the Python API and `rustscenic add-cor` command.
- Added warnings when few topics dominate a fit, plus run records of settings,
  active topics and empty cells to help users assess the results.
- Moved the new release line to Apache-2.0, with typed APIs, cross-platform
  packaging, citation metadata and reproducible validation records.

## Upgrade

```bash
pip install --upgrade rustscenic==0.5.0
```

To reproduce older GRN stopping behaviour, set
`early_stop_mode="legacy_inbag"`. Regulons now preserve activator/repressor
polarity by default; use the documented `"unsigned"` compatibility mode when
needed. Correlation signs are not experimental proof of regulatory direction.
Earlier 0.4.x releases remain available under MIT.

This release does not include the unfinished CELLxGENE community-resource
workflow or claim a complete million-cell spatial pipeline.
