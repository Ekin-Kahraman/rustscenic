## Current-branch same-source reruns

Rerun 2026-08-15 on the uncommitted review set based on `98e52c7`, using the
release extension rebuilt from that source. The local machine was an Apple M5
running macOS 26.5 and Python 3.13.9. Rayon was limited to ten threads and
OpenMP, OpenBLAS, MKL and Accelerate were each limited to one. Each result is a
single observation with uncontrolled cache state, so cross-machine timings are
reported as observations rather than speedups.

### #94 exact 10x brain inputs

The local 10x HDF5, peak BED and fragment TSV have MD5 values
`7974b9f36f17f560db1aacf1c7196c1d`,
`95fc619db6b6e82e0e2f74a084357278` and
`15a4f42c2b8841fc9423ae45d81177b0`. They match the official manifest and the
input identities recorded in #94. The issue does not provide the random
downsampling seed or transformation script, so the derived fragment file
cannot be shown to be byte-identical.

The issue's unfiltered `fragments_to_matrix(fragments, peaks)` call reproduced
its exact 644,847 x 130,127 shape. It produced 85,585,775 non-zero entries in
53.12 seconds with 4.01 GB maximum resident set. The matrix sum was
114,899,746; the full-file fragment-record and fragment-count totals were
269,676,761 and 465,481,759. The expected raw-barcode warning was emitted.

The production form, using all 10,261 cell-called barcodes from the matching
filtered-feature HDF5, matched every requested barcode and returned 10,261 x
130,127 with 83,158,252 non-zero entries. It took 52.08 seconds and 3.81 GB
maximum resident set. This directly validates the bounded-row path on the same
source, but it is not peak-calling correctness evidence and does not cover the
45 GB Bhat-Nakshatri GEO archive or its unavailable downsample/cluster script.

### #69 exact 10x lymphoma source

The official Cell Ranger ARC 1.0.0 filtered-feature HDF5 was downloaded from
the URL in #69 and verified against 10x's MD5
`e0edcb64500137a3fdd4ab83ab791640` (SHA-256
`042bde68956f7b18f24d1ba98ebd85ebb69343c63e3aea25ed9d53bab56866ce`).
The issue omitted its H5AD, cell list, QC thresholds and TF list, so the exact
14,039 x 27,178 derived matrix cannot be reconstructed. The checked-in runner
`validation/run_issue69_lymphoma.py` instead records an explicit transform:
minimum 200 genes per cell, minimum three cells per gene, total-count 10,000
normalisation and `log1p`. This yielded 14,208 x 27,504 before deterministic
duplicate-symbol summation and 14,208 x 27,495 for fitting.

With the issue's 300-estimator ceiling, seed 777 and corrected `arboreto`
stopping, the full GRN completed in 1,708.73 seconds and the complete signed
GRN/AUCell path in 1,715.35 seconds at 1.78 GB maximum resident set. It fitted
733,388 trees across 27,495 targets (minimum 25, median 26, mean 26.674,
maximum 162), emitted 2,512,159 edges and split them into 803,677 activating,
18,421 repressing and 1,690,061 neutral edges. Top-50/minimum-10 construction
produced 1,669 activator and 144 repressor regulons; AUCell returned 14,208 x
1,813. POU2F2, PAX5, MEF2B, SPIB, EBF1 and BCL11A, the B-cell regulators
highlighted in #69, each had distinct activator and repressor programmes.

As an independent same-source early-stop check, scikit-learn 1.7.2 was fitted
with the arboreto parameters and its modern `oob_improvement_` trailing window
was evaluated for six fixed targets. Upstream/Rust fitted-tree counts were:
A1BG 28/27, A2M 26/25, CD74 26/25, MS4A1 63/77, CD79A 25/26 and HLA-DRA
34/27. The median absolute difference was one tree and the maximum was 14.
Exact equality is not expected from different tree builders; the comparison
confirms the same stop boundary and distribution on this source rather than
only on PBMC3k.

The signed parquet SHA-256 was
`a4a52d78784bb8d7cb27ab38abb73c2cc6814742c5400e077529ae00436a2a01`.
An independent SciPy `pearsonr` check of 2,000 edges sampled without
replacement using seed 690096 had zero polarity mismatches and maximum
absolute rho difference `1.42e-7`; the little-endian int64 sample-index hash
was `df3f02eaf78b07251d8a6fd6a632ed6717332c06c0d54b6c016bf9e87b5fabbd`.
Generated inputs and outputs remained under `/tmp` and were not added to Git.

### #85 exact GEO source

The public RNA and ATAC count matrices were recovered from GEO GSE204683 and
GSE204682. The RNA RDS SHA-256 was
`48b313be5330fce66a68c5f76a655e4fc71505048d9010fd2bd8ce519bd67d13`
and contained 45,549 cells x 30,201 genes; the ATAC RDS SHA-256 was
`09e9ab3589af17c1854658d9e61619ad76938989601a3d86bb782dcdbf2ce038`
and contained the same 45,549 cells x 304,034 peaks. The issue's 44,222-cell
selection, converted H5AD, gene-coordinate build and exact thresholds were not
attached, so this is the same public source rather than the unavailable exact
derived objects.

After total-count 10,000 normalisation and `log1p`, the seven issue TFs were
run with seed 777, the corrected `arboreto` rule and the production 5,000-tree
ceiling. GRN inference took 165.63 seconds at 2.62 GB maximum resident set and
emitted 181,200 edges. It fitted 791,641 trees over 30,201 targets (minimum 25,
median 26, mean 26.212, maximum 107). Correlation took 0.72 seconds and split
10,056 activating, 5,955 repressing and 165,189 neutral edges. Top-50/minimum-
10 construction produced eleven signed regulons: both polarities for NEUROD1,
NEUROG2, BHLHE22, CUX2 and HESX1, plus an E2F2 activator. EN1 remained absent,
reproducing the report's six-of-seven biological recovery without silently
collapsing polarity. The signed parquet SHA-256 was
`bd5575bb3aee10ab8448f7a83bce27ed145d188358139908eb6c6856b3291cbb`.

This same-source GRN result directly validates issues #95 and #96, but it does
not resolve #85's zero-eRegulon result. That requires the omitted 44,222-cell
selection, hg19 gene-coordinate construction, thresholds and motif-pruning
configuration in a correctly packed one-host Minerva rerun.
